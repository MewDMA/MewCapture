# MewCapture screenshots

Real screenshots of the MewCapture app for mewdma.net and its Learn guides. Each one is 1600x1000 (16:10) PNG. Taken on **MewCapture 1.0.7**.

The app ran with placeholder data: the PCs are called MAIN-PC and SECOND-PC, the addresses are 192.168.0.x, the folder is C:\Users\you, and the game and overlay pictures are placeholders. No stream keys, names, emails or tokens are in any of them.

## For the /capture setup steps

| File | What it shows |
| --- | --- |
| capture-pick-pc.png | The first screen, where you pick Main PC or Second PC. |
| capture-pick-overlay.png | Your Overlay on the second PC: the picked overlay window, the live preview with its background removed and the "How much gets removed" slider. |
| capture-pair-code.png | Both PCs showing the same 4-digit code, the main PC on the left and the second PC with Connect on the right. |
| capture-main-send.png | The Main PC screen: Start sending, what to send (Screen or Game window) and which apps' sound goes along. |
| capture-output.png | Output on the second PC: the YouTube, Twitch, Low impact and Clips only presets, Start recording and Go live. |
