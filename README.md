## What it does

<table>
<tr>
<td width="50%" valign="top">

**No capture card**<br>
The main PC sends the game to the second PC over your network or one Ethernet cable, up to 4K or 144 fps

</td>
<td width="50%" valign="top">

**Barely costs fps**<br>
Straight from the screen into your graphics card's video encoder, low priority, no preview. It shows you how little it uses

</td>
</tr>
<tr>
<td valign="top">

**Your overlay, safely**<br>
The overlay only ever runs on the second PC. Its background gets removed by itself, and MewCapture warns you if an overlay shows up on the main PC

</td>
<td valign="top">

**Never touches the game**<br>
Captures the screen like Discord streaming does. No hooks, no DLLs in the game, no reading its memory

</td>
</tr>
<tr>
<td valign="top">

**Scenes like OBS, but simple**<br>
Game, overlay, webcam with background blur, images, text, countdowns, browser sources, keys and mouse. Studio mode and smooth transitions

</td>
<td valign="top">

**Clip That**<br>
One hotkey on either PC saves the last 30 seconds to 2 minutes, with the overlay or clean. Trim it and send it to the main PC

</td>
</tr>
<tr>
<td valign="top">

**Record and stream**<br>
Presets for YouTube, Twitch, Low impact and Clips only. Go live on Twitch, YouTube and Kick at once, with the chat inside the app

</td>
<td valign="top">

**Mixer**<br>
Meters, mute and push to talk. Game, mic and Discord on their own tracks in recordings

</td>
</tr>
<tr>
<td valign="top">

**Pairs by itself**<br>
Both PCs show the same code once, then they find each other and reconnect by themselves, over Wi-Fi, Ethernet or a direct cable

</td>
<td valign="top">

**Something's wrong button**<br>
Checks both PCs and the link, tells you what's off and how to fix it, and makes a summary you can paste in a ticket

</td>
</tr>
</table>

## Install

1. Download the installer from <a href="https://github.com/MewDMA/MewCapture/releases/latest">releases</a> and install it on **both** PCs
2. Run it. Windows might say "Windows protected your PC", click More info then Run anyway. That's just because the app isn't code signed yet
3. Open MewCapture, it asks for admin so it can open the firewall for the other PC. Never run your overlay on the main PC
